# CPOE — COM-Poisson Orthogonal Expansion

*Read this in other languages: [한국어](README.ko.md)*

This repository contains the complete computing pipeline for the manuscript

> Ji-Hun Lee, Chae-Yon Lee, Hyung-Tae Ha (2026),
> **"Semi-Parametric Extensions of the Conway--Maxwell--Poisson Distribution via
> Orthogonal Polynomial Bases"** (under review).

Every number, table, and figure in the paper's numerical sections is produced by
the code in this repository, deterministically: re-running the pipeline
reproduces the published values bit-for-bit (fixed seeds, no wall-clock or
environment dependence in any reported quantity).

## 1. The model in one paragraph

The COM-Poisson (CMP) distribution `w_CMP(x; λ, ν) ∝ λ^x / (x!)^ν` generalizes
the Poisson distribution with a dispersion parameter ν, accommodating both
over-dispersion (ν < 1) and under-dispersion (ν > 1) — but it remains a
two-parameter family: it can match a mean and a variance, not skewness,
kurtosis, multimodality, or heavy tails. CPOE removes that limitation by
multiplying the CMP baseline with a polynomial tilt,

```
p_θ(x) = w_CMP(x; λ, ν) · (1 + Σₙ θₙ ψₙ(x; λ, ν)),
```

where `{ψₙ}` is the orthonormal polynomial system of the CMP weight (constructed
numerically — it has no closed form) and `θ = (θ₁, …, θ_K)` are expansion
coefficients with the normalization `θ₁ = θ₂ = 0` (the mean and variance
directions are already absorbed by λ and ν; θ₃ acts on skewness, θ₄ on
kurtosis). Orthogonality makes the tilt integrate to one automatically; only
non-negativity can fail, which confines θ to the convex feasibility polytope
`C_K = {θ : 1 + θᵀψ(x) ≥ 0 for all x}`. The paper develops three estimators for
(λ, ν, θ) and a risk-based rule for choosing the truncation order K.

## 2. Data

Two real datasets and four simulated scenarios are used (paper Section 6). The
raw CSVs ship with the repository; **all preprocessing is deterministic code**
(`src/cpoe/data_prep.py`, loaded through `experiments/_datasets.py`), so no
manual data step is ever required.

| Dataset | N | Shape | Source / license |
|---|---|---|---|
| FIFA | 964 | mildly over-dispersed, unimodal (V/M = 1.32) | Kaggle `martj42/international-football-results-from-1872-to-2017`, CC BY 4.0 |
| Insurance-smoker | 274 | genuinely bimodal (V/M = 2.85) | Kaggle `mirichoi0218/insurance`, ODbL |
| S1–S4 | 1500 each | simulated, see below | generated by `experiments/highk_scenarios.py` |

- **FIFA** — total goals per FIFA World Cup match: rows with
  `tournament == "FIFA World Cup"` are kept and the count is
  `home_score + away_score`. A mildly over-dispersed unimodal benchmark that a
  CMP baseline almost fits on its own.
- **Insurance-smoker** — medical charges discretized in $1,500 bins
  (`floor(charges / 1500)`), restricted to smokers. The smoker subsample
  isolates a genuinely bimodal count shape that no unimodal baseline can
  reproduce — the paper's hardest real dataset.
- **S1–S4** — equal-weight (50:50) two-component mixtures spanning four shape
  regimes: S1 under-dispersion, S2 over-dispersion, S3 a heavy tail with a weak
  second mode (0.5·Poisson(2) + 0.5·Poisson(8)), and S4 over-dispersion plus
  bimodality (0.5·NB(2, 0.4) + 0.5·(CMP(3, 0.5)+9)). Because the generating
  mixture is known exactly, simulation fits can be scored against the *true*
  pmf, giving genuine risk estimates. All in-sample analyses use one
  **fixed-seed representative sample per scenario** at N = 1500
  (seed `20260606 + 1000·(scenario index + 1)`); the Monte Carlo study draws
  replicated samples from the seed map `default_rng([scenario_id, N, r])`.

Details and the license roll-up are in [`data/README.md`](data/README.md).

## 3. Pipeline overview

The pipeline mirrors Algorithm 1 of the paper ("CPOE numerical pipeline"). Every
quantity — normalizing constant, moments, basis, tilted pmf, estimators — lacks
a closed form and is computed numerically on an adaptively truncated support
`S_M = {0, …, M}`:

```
                 ┌────────────────────────────────────────────────────────┐
                 │  src/cpoe  (library — the numerical core)              │
                 │                                                        │
  data/*.csv ─►  │  ① compoisson   log Z, moments  (log-sum-exp, tol 1e-12)│
  scenarios  ─►  │  ② basis        ψₙ via three-term recurrence (Stieltjes)│
                 │  ③ cpoe_model   tilted pmf  p_θ = w·(1+θᵀψ)             │
                 │  ④ feasibility  C_K polytope diagnostics + L² projection│
                 │  ⑤ estimators   MoM │ Sequential MLE │ Joint MLE        │
                 │  ⑥ order_selection   R̂(K) profile → K̂_RISK             │
                 └───────────────┬────────────────────────────────────────┘
                                 │  shared fit core: experiments/highk_optimal_k
                 ┌───────────────▼────────────────────────────────────────┐
                 │  experiments  (drivers — one script per paper artifact) │
                 │  crossmodel_eval · l2_eval · highk_report ·             │
                 │  data_pmf_overview · compute_orderselection ·           │
                 │  mc_simulation → mc_tables · task1_basis_comparison     │
                 └───────────────┬────────────────────────────────────────┘
                                 ▼
        papers/figs (body figures) · papers/supp (supplement) · results/ (CSV)
```

Two structural facts guarantee internal consistency:

1. **One shared fit path.** Every in-sample fit in every table and figure goes
   through `experiments/highk_optimal_k._fit_one` / `_pmf`, so numbers agree
   across artifacts by construction (the Monte Carlo study calls the same
   estimators directly).
2. **One shared inner solver.** The Sequential and Joint MLEs use the *same*
   convex θ-solver (`solve_theta_at_baseline`, trust-region interior Newton
   with analytic gradient/Hessian and exact KKT conditions), so feasibility
   enforcement is identical and the estimators differ only in whether (λ, ν)
   responds to the tilt.

## 4. Library modules (`src/cpoe/`)

| Module | Role |
|---|---|
| `compoisson.py` | CMP core: `log Z(λ, ν)` by adaptive truncation + log-sum-exp (residual tolerance 1e-12, monotonicity streak 5 — paper eq. for `log Z`), mean/variance, pmf, and the large-λ asymptotic warm start of Shmueli et al. (2005). Loads `config/hyperparams.yaml`. |
| `basis.py` | Orthonormal polynomial system `{ψₙ}`. Primary route: **three-term recurrence** whose coefficients come from a discretized-Stieltjes (Lanczos) procedure with modified Gram–Schmidt re-orthogonalization — machine-precision orthonormality (~1e-12) at all degrees. The moment-based Hankel/Cholesky route is retained only as a low-degree cross-check: its condition number grows exponentially with degree (orthonormality degraded to ~1e-6 by degree 9; see `task1_basis_comparison`). |
| `cpoe_model.py` | Tilted pmf `p_θ` and the projection identity `θₙ = E_p[ψₙ(X)]` (paper eq. 14) — the common anchor of all three estimators; `empirical_theta` is its plug-in form. |
| `feasibility.py` | The feasibility polytope `C_K` realized on the truncated support: violation/margin diagnostics and the Euclidean projection `project_onto_C_K` used to restore infeasible raw MoM projections. |
| `backends.py` | Thin adapter (`CMP_BACKEND`, `BASIS_BACKEND`, `default_M`) joining the CMP/basis code to the estimators. |
| `sampling.py` | Samplers for CMP and exact-tilt CPOE distributions (used by the simulation scenarios). |
| `data_prep.py` | Deterministic preprocessing of the two real datasets. |
| `diagnostics.py` | `empirical_pmf`, `l1_distance`. |
| `baselines.py` | Moment-matched Poisson / negative-binomial / CMP baseline pmfs for the cross-model comparison. |
| `order_selection.py` | Risk-based order selection: projection statistics `(θ̂ₙ, σ̂ₙ²)`, the risk profile `R̂(K) = Σₙ₌₃^K (2σ̂ₙ²/N − θ̂ₙ²)`, and `K̂_RISK = argmin R̂(K)` — an unbiased estimator of risk *differences* across orders (paper Proposition 4). Also ships verification-only companions (not used in the paper's tables): `BIC(K)`/`K̂_BIC`, the within-replication oracle `K*`, and the residual-energy diagnostic `Ê^{1/2}`. |
| `estimators/mom_sandwich.py` | Verification-only two-step **sandwich covariance** for the MoM estimator: stacked just-identified Z-estimation over `(λ, ν, θ₃…θ_K)` propagating the stage-1 plug-in error into `SE(θ̂ₙ)`; cross-checked against the fixed-basis SE and the Monte Carlo standard deviation (`mc_tables.py` SE-check table). |
| `estimators/mom.py` | **Method of Moments**: Newton solve of the moment-matching system `μ_CMP = X̄`, `σ²_CMP = S²`, then the closed-form empirical projection `θ̂ₙ = N⁻¹ Σᵢ ψₙ(Xᵢ)`; if the raw projection leaves `C_K` it is restored by the Euclidean QP. Cheapest of the three. |
| `estimators/cmp_baseline.py` | Pure CMP maximum likelihood (concave in the natural parameterization) — stage 1 of the Sequential estimator. |
| `estimators/mle_sequential.py` | **Sequential (two-stage, limited-information) MLE**: fit the baseline by CMP-MLE, then maximize the tilt likelihood over `θ ∈ C_K` with the baseline held fixed — one call to the shared convex inner solver. |
| `estimators/mle.py` | **Joint (full-information) MLE**: nested profile optimization. The outer loop maximizes the profile `g(λ, ν) = max_θ ℓ_N(λ, ν, θ)` by a truncated-Newton (TNC) method using the analytic envelope (Danskin) gradient at the inner optimum; multistart (moment-based start + Sequential solution) guarantees `ℓ_Joint ≥ ℓ_Seq`; a validity gate (inner feasibility together with `ℓ_N ≤ 0`) rejects degenerate normalization-collapse optima at high order. |

Numerical policy: every arbitrary threshold (truncation tolerance, parameter
box) lives in `config/hyperparams.yaml` — no module hardcodes a regime
threshold, so sensitivity sweeps are one-line configuration changes.

## 6. Reproducing everything

```bash
# environment (Python >= 3.11)
uv sync                    # or: pip install -e .

# full regeneration (in-sample pipeline ~20 min total)
python experiments/data_pmf_overview.py
python experiments/crossmodel_eval.py
python experiments/l2_eval.py
python experiments/highk_report.py
python experiments/compute_orderselection.py
python experiments/mc_tables.py            # from the shipped MC archive
python experiments/task1_basis_comparison.py

# optional: re-run the Monte Carlo study itself (hours)
python experiments/mc_simulation.py --R 500

# optional: verification-only extras (not used by the paper's tables)
python experiments/est2nd_eval.py                    # feasibility + fit-time table (~30 min, Joint fits)
python experiments/mc_simulation.py joint --R 100    # Joint reduced-design MC (verification)
```

Determinism: in-sample sampling uses the fixed seed 20260606 (per-scenario
offsets), the Monte Carlo uses the structured seed map
`default_rng([scenario, N, replicate])`, and all optimizers are deterministic —
regenerated CSVs are byte-identical across runs.

The supplement source is `papers/supp/supplementary.tex`; it `\input`s the
auto-generated tables in `papers/supp/tables/` and the figures in
`papers/supp/figs/`, so it compiles directly after the pipeline has run.
